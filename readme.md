# 🎱 로또 번호 생성기 (Lotto Number Generator)

Streamlit을 활용하여 만든 직관적이고 시각적인 로또 번호 생성 웹 애플리케이션입니다. 실제 대한민국 로또 공 색상 규정에 맞춘 컬러풀한 UI를 제공하며, 최대 5세트까지 번호를 생성하고 확인할 수 있습니다.

---

## ✨ 주요 기능

- **실제 로또 공 색상 적용**: 
  - 1 ~ 10: 🟡 노란색
  - 11 ~ 20: 🔵 파란색
  - 21 ~ 30: 🔴 빨간색
  - 31 ~ 40: ⚫ 회색
  - 41 ~ 45: 🟢 초록색
- **세션 상태 유지 (`st.session_state`)**: 새로고침 없이 생성된 번호 기록이 안전하게 유지됩니다.
- **세트 제한 기능**: 최대 5세트까지만 생성할 수 있도록 제한하여 깔끔한 화면을 유지합니다.
- **초기화 버튼**: 생성된 기록을 간편하게 리셋할 수 있습니다.

---

## 🛠️ 설치 및 실행 방법

### 1. 사전 요구사항
- Python 3.8 이상이 설치되어 있어야 합니다.

### 2. 패키지 설치
터미널(또는 명령 프롬프트)을 열고 필요한 패키지를 설치합니다:
```bash
pip install -r requirements.txt
```

### 3. 애플리케이션 실행
설정이 완료되면 아래 명령어로 Streamlit 앱을 실행합니다:
```bash
streamlit run app.py
```
*(파이썬 파일명을 `app.py`로 저장했다고 가정합니다.)*
